# ML Mini-Projects

Коллекция самостоятельных мини-проектов по машинному обучению, статистике и анализу данных. Каждый проект представляет собой законченное решение конкретной задачи с полным кодом, документацией и зависимостями.

## Цель репозитория

Этот репозиторий служит портфолио практических навыков. В отличие от учебных упражнений, каждый мини-проект:
- Решает реальную или приближенную к реальной задачу
- Содержит полноценное описание в собственном README
- Имеет файл зависимостей для воспроизводимости
- Демонстрирует понимание математических основ алгоритмов

## Структура

Каждый проект находится в отдельной папке с понятным названием на английском языке (kebab-case):

```text
ml-mini-projects/
├── mini-project-1/       # Первый мини-проект
│   ├── project-1.py
│   ├── README.md
│   └── requirements.txt
├── mini-project-/      # Второй мини-проект
│   ├── ...
└── README.md               # Этот файл
