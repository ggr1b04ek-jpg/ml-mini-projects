# Байесовский A/B-тест

Мини-проект, демонстрирующий применение байесовского вывода для сравнения конверсии двух версий продукта. 

В отличие от классических частотных тестов, которые оперируют p-value и нулевыми гипотезами, байесовский подход позволяет дать прямой и интуитивно понятный ответ на бизнес-вопрос: "Какова вероятность того, что версия B конвертит лучше версии A?".

## Математическая основа

Проект опирается на концепцию сопряженных априорных распределений (Conjugate Priors):
- Данные (клики/покупки) моделируются как распределение Бернулли.
- Априорное убеждение о конверсии кодируется Бета-распределением (Beta Prior).
- Благодаря сопряженности, апостериорное распределение (Posterior) также является Бета-распределением, что позволяет обновлять знания аналитически, без сложных интегралов.
- Для оценки вероятности превосходства одной версии над другой используется метод Монте-Карло.

## Параметры эксперимента

- Prior (априорное знание): Beta(2, 18) — отражает слабую уверенность в том, что базовая конверсия находится в районе 5-10%.
- Данные эксперимента:
  - Версия A (контроль): 15 конверсий из 200 показов (7.5%).
  - Версия B (тест): 28 конверсий из 200 показов (14.0%).
- Posterior (апостериорное знание):
  - Версия A: Beta(17, 203)
  - Версия B: Beta(30, 190)
